# Mini Data-Analysis: Deliverable 1

This repository contains my Mini Data-Analysis Deliverable 1 for the course. The report explores the `hcmst` data set (from Stanford's "How Couples Meet and Stay Together" study, adapted in the `diversedata` package) to answer questions about relationship quality, how often partners fight, and how income changes during the pandemic relate to how people rate their relationships.

## Files

- `MiniDataAnalysis1.qmd` — the source Quarto document with all of the code and written answers
- `MiniDataAnalysis1.md` — the rendered output of the Quarto document
- `dat/` — data folder for the course
- `A2.pdf`, `A2.qmd` — files from a previous assignment kept in this repo

## How to engage with this repository

To reproduce the report, open `MiniDataAnalysis1.qmd` in RStudio and render it with Quarto. You will need the `tidyverse`, `diversedata` (installed with `pak::pak("diverse-data-hub/diversedata")`), and `moderndive` packages. The data is loaded through the `diversedata` package, so nothing needs to be downloaded manually.
